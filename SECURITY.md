# SmartVolt Security Policy

## Scope

This repository is part of the SmartVolt project family. Security reports should be handled privately and responsibly.

## Reporting a vulnerability

Do not publish credentials, tokens, private keys, personal data, or an exploitable vulnerability in a public issue.

If private vulnerability reporting is available in this repository, use GitHub's private security reporting mechanism. Otherwise, contact the repository owner through a private GitHub channel.

## Secrets

Never commit API keys, passwords, access tokens, private keys, `.env` files containing secrets, or other credentials.

Use placeholders such as `.env.example` for configuration documentation.

## Preservation principle

Security fixes must be added as new commits. Existing history must not be rewritten or erased without explicit authorization.

## Responsible disclosure

Please provide enough information to reproduce and validate the issue, while avoiding unnecessary exposure of sensitive data.
